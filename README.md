
## What it does

The Mechatronics Quiz App is a Python-based multiple-choice application designed to test students' knowledge of Mechatronics Engineering.

It asks questions, checks answers automatically, calculates scores and displays the student's final grade.

## How to run it

1. Install Python 3.
2. Download the project from GitHub.
3. Open the project folder in your terminal.
4. Run:

python mechatronics_quiz.py

## Sample output

Student Name: Christian
Total Questions: 10
Correct Answers: 8
Wrong Answers: 2
Percentage: 80.0%
Grade: A - Excellent!

## My own twist

I added an Incorrect Answer Revision System.

It identifies questions answered incorrectly and displays their correct answers after the quiz.
